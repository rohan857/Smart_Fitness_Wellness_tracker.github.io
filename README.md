# Smart Fitness and Wellness Tracker

A responsive GitHub Pages dashboard that estimates steps from a phone's motion sensor while the page is open. It also provides manual wellness check-ins for heart rate, blood pressure, SpO2, and body temperature.

## Use

Open the published site on a phone, select **Tracker**, press **Start tracking**, and allow motion access. The page must remain visible while tracking.

Daily activity totals reset automatically when the date changes. Wellness readings are entered manually and are not measured by the browser.
